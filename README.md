## 📖 Overview

**UniMap** is a web-based indoor navigation system developed to simplify navigation inside university buildings. The system allows users to search for locations, display interactive maps, calculate the shortest path between rooms, manage favorite locations, and view class schedules through an intuitive interface.

---

## ✨ Features

- 🔍 Search for classrooms, offices, and facilities
- 🗺️ Interactive multi-floor campus maps
- 📍 Shortest path navigation using the A* algorithm
- ⭐ Favorite locations
- 🌙 Dark Mode
- 📅 Schedule integration
- 👤 User authentication
- 📱 Responsive design
